# BenchMax v2.0.1

A patch release: fairer scores, shareable results, smoother history. Nothing to reinstall, no migration steps.

## Fairer scores

A full grading audit fixed real bugs that were skewing results:

- **BigCodeBench (+Hard) grades correctly now.** Questions needing files, spreadsheets, or third party packages used to fail no matter what the model wrote. All 10 quick-test reference solutions pass.
- **BFCL runs again.** It crashed before the first question; multi-turn runs also report honest speed and per-turn details now.
- **LiveBench reasoning, language, and data questions** were graded as multiple choice despite having no options, so they always failed. They are graded on their real answers now.
- **Hedged answers no longer score** on any multiple choice benchmark. Only one clear answer counts.
- **Broken questions fail loudly** instead of silently passing, so a high score always means earned.
- **Aider Polyglot:** a Java task that could never pass now can; retry speed stats combine both attempts.

Small score shifts vs older runs on these benchmarks are the fixes at work, not a regression.

## LiveBench without Docker

Coding questions are now skipped upfront with a clear message when Docker is missing, instead of wasting model time on questions that can never pass. The other five categories run normally. A half-Docker badge marks LiveBench everywhere it is listed.

## Trusted Cards

Any run now produces a copy-ready text card: model, settings, context, hardware, score with correct/total, token split, speed. Quick tests and unfinished runs are labeled as such, so a 5/5 quick test never poses as a full win. Copy one card from run details, or select several runs and copy them all.

## History multi-select

Ctrl/Cmd-click to toggle, Shift-click for a range, header checkbox for the page. The selection bar offers Compare, Copy cards, Export (CSV/JSON/Excel), Delete with confirmation, and Clear.

## Complete exports

Every export now carries the full picture: per-question files stamp each row with the model, its settings, and flags; history and leaderboard files include the token split, limits, and system prompt; run reports add a configuration section, a table of every question, and the full prompt plus model answer for each failure.

## Fixes

- Refresh no longer wipes live progress mid-run
- Fast clicking no longer flashes the wrong run's details
- Clearing history clears the detail panel too
- Model queue no longer dies with an event loop error between load and run
- Docker benchmarks warn upfront when Docker is missing
- Deleting a run mid-execution stays quiet
